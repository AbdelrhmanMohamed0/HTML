# HTML Assignments (Lessons 1 to 37) - Elzero Web School

This repository contains all my completed HTML assignments from lessons **1 to 37** of the [Elzero Web School](https://elzero.org/html-assignments/) course. The assignments cover a wide range of HTML topics from basic tags to advanced form handling.

## 📘 What I Did

I have completed **all 37 HTML assignments** as part of the structured learning path in the course. Below is a summary of the topics and tasks covered:

### ✅ Lessons 1–10
- Created a basic HTML page structure using `<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>`.
- Learned how to use headings, paragraphs, comments, and special characters.
- Used formatting elements like `<strong>`, `<em>`, `<mark>`, `<del>`, and `<ins>`.

### ✅ Lessons 11–20
- Used `<a>` for hyperlinks and learned about `target` and `href`.
- Implemented lists: ordered (`<ol>`) and unordered (`<ul>`).
- Worked with images and learned about the `alt`, `width`, and `height` attributes.
- Used tables (`<table>`, `<thead>`, `<tbody>`, `<tfoot>`) and structured data properly.

### ✅ Lessons 21–27
- Introduced to form basics with `<form>`, `<input>`, `<label>`, `<textarea>`, `<select>`, and `<option>`.
- Used different input types: text, password, number, date, radio, checkbox, etc.
- Practiced form structure and validation.

### ✅ Lessons 28–30 (Form Advanced - Part Two)
- Built a complete form with advanced validation and hidden inputs.
- Implemented input restrictions, autofocus, required fields, and default values.
- Added checkboxes for skills, radio buttons for job roles, dropdown menus with grouped options, and textareas with default text.

### ✅ Lessons 31–37
- Learned about semantic HTML elements: `<header>`, `<footer>`, `<nav>`, `<section>`, `<article>`, `<aside>`, `<main>`.
- Applied best practices for page layout and accessibility.
- Used iframes, `download` attribute, and embedded content.
- Practiced nesting elements correctly and organizing HTML content in a clean structure.
